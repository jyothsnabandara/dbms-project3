## Overview

This GitHub repository contains the complete DBMS Project 3 full-stack application. The project was developed using Python, Flask, SQLAlchemy, SQLite, HTML, CSS, Bootstrap, and Jinja2 templates.

The repository includes the application source code, normalized SQL schema, normalization report, AI assistance disclosure, setup instructions, and version-control documentation. The application supports student, course, enrollment, assignment, and submission management while maintaining database integrity through validation, relationships, and transaction logic.
